# Как начать

## 1. Подключи чужую книжку (2 минуты)

Владелец книжки присылает тебе команду с личным токеном. Выполни её один раз и запусти Claude Code:

```bash
claude mcp add --transport http pasha "https://адрес/mcp" --header "Authorization: Bearer nb_..."
claude
```

Дальше обычным языком: «Спроси у книжки Паши, есть ли у него кто-то, кто закупает платный трафик на подписочный продукт». Или `/ask-network`, если ты запустил Claude в этой папке.

## 2. Собери свою, сначала на демо (5 минут)

```bash
git clone https://github.com/chemp1/hegai-network-mcp.git
cd hegai-network-mcp
npm run demo
node scripts/guests.mjs add "Я сам"
claude mcp add book-local -- node "$PWD/scripts/server.mjs" --stdio
claude
```

Спроси: «Что есть в book-local?», потом «Нужен директолог в Москве», потом «Есть там Демид Вымыслов?». Последний вопрос должен получить `нужно_уточнить`: имена тут не ищутся.

## 3. Замени демо на свои данные

```bash
rm -rf data/*
claude
```

`/book-import`, затем `/book-tag`, затем `/book-publish`. Claude спросит, что и кому показывать, и покажет витрину до того, как ты что-то откроешь.

## 4. Открой книжку наружу

В двух терминалах:

```bash
node scripts/server.mjs
cloudflared tunnel --url http://127.0.0.1:8787
```

`cloudflared` ставится за минуту: [инструкция](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/). Аккаунт для быстрого туннеля не нужен. Адрес покажется в терминале, он вида `https://что-то.trycloudflare.com`.

Выдай токен каждому гостю отдельно:

```bash
node scripts/guests.mjs add "Андрей" --url https://что-то.trycloudflare.com/mcp --expires 30d
node scripts/guests.mjs list
node scripts/guests.mjs revoke "Андрей"
```

## Если что-то не так

| Симптом | Причина |
|---|---|
| `401` | токена нет или он отозван, спроси у владельца новый |
| сервер недоступен | у владельца закрыт ноутбук или адрес туннеля сменился после перезапуска |
| всегда `нужно_уточнить` | запрос не попал в теги: попроси Claude сначала вызвать `network_overview` |
| витрина пустая | мало тегов: прогони `/book-tag` или снизь `min_showcase` в `data/policy.json` |
