# Открыть книжку

Перед открытием человек должен своими глазами увидеть, что увидят гости.

## Порядок

1. Если нет `data/policy.json`, создай его из `policy.example.json`. Заполни с человеком `owner`, `about`, `rules`. Спроси про `share_companies` (по умолчанию выключено): компания плюс роль часто равны имени.
2. `node scripts/build-index.mjs` и покажи витрину. Спроси: что убрать (`showcase_hide`), какие темы не отдавать совсем (`stop_tags`), кого спрятать (`hide`). После правок пересобери.
3. Проверь себя как гость:
   ```bash
   claude mcp add book-local -- node "$PWD/scripts/server.mjs" --stdio
   ```
   Задай пару вопросов и попробуй спросить про конкретного человека: сервер должен ответить `нужно_уточнить`.
4. Запусти сервер и туннель, каждый в своём терминале:
   ```bash
   node scripts/server.mjs
   cloudflared tunnel --url http://127.0.0.1:8787
   ```
   Без аккаунта адрес временный и меняется при каждом запуске. Постоянный вариант описан в `docs/24-7.md`.
5. Выдай гостя с адресом из туннеля:
   ```bash
   node scripts/guests.mjs add "Имя" --url https://адрес.trycloudflare.com/mcp --expires 30d
   ```
   Команду с токеном человек пересылает гостю лично. Сам ты никому ничего не отправляешь.

Если человек спрашивает, что будет, когда ноутбук закрыт: сервер недоступен, а запросы подождут. Это честное ограничение локального варианта.
