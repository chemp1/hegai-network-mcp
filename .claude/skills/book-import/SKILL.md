# Собрать книжку

Ничего не уходит в сеть. На выходе `data/book.jsonl`: строка на человека, имя, должность, компания, круг, теги по правилам.

## Порядок

1. Спроси, что у человека уже есть, и найди файлы сам:
   - папка `out/` Личной CRM (`hegai-lichnaya-crm`, воркшоп 02), там `circles.json`;
   - `Connections.csv` из LinkedIn (воркшоп 03);
   - `enriched.json` из воркшопа 03;
   - любой CSV с колонками `name,title,company,city,tags,circle,tg`.
2. Ничего нет: `npm run demo`, это выдуманная книжка на 164 человека. Скажи, что данные выдуманные.
3. Запусти импорт с тем, что нашлось:
   ```bash
   node scripts/import.mjs --crm ../hegai-lichnaya-crm/out --linkedin ./Connections.csv
   ```
4. Покажи итог: сколько людей, сколько с тегами. Предложи `/book-tag`, если тегов мало. У контактов только из телеграма должности нет, теги по правилам там пустые, и это нормально.

Файл `book.jsonl` не открывай целиком и не выводи в чат: в нём живые имена.
